# Hospital Inventory Management System

## Project Description

The Hospital Inventory Management System is a Django-based web application designed to help hospital staff manage and monitor medical inventory.

The system will allow authorized staff to:

- Log in securely
- View current inventory levels
- Add, edit, and update inventory items
- Search and filter inventory
- Monitor low-stock items
- Receive low-stock alerts
- Generate inventory reports
- Track inventory usage
